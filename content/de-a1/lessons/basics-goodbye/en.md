Leaving politely matters as much as greeting. Here are the goodbyes and the small polite words you will use every day.

## Goodbyes

| Deutsch | English | Use |
|---|---|---|
| Auf Wiedersehen! | Goodbye! | formal |
| Tschüss! | Bye! | informal |
| Bis bald! | See you soon! | friends |
| Bis später! | See you later! | same day |
| Bis morgen! | See you tomorrow! | |
| Bis dann! | See you then! | |
| Schönen Tag noch! | Have a nice day! | shops, offices |
| Schönes Wochenende! | Have a nice weekend! | Friday |
| Auf Wiederhören! | Goodbye! | on the phone only |

## Polite words

| Deutsch | English |
|---|---|
| bitte | please / you're welcome |
| danke | thank you |
| Danke schön! / Vielen Dank! | Thank you very much! |
| Bitte schön! / Gern geschehen! | You're welcome! |
| Entschuldigung! | Excuse me! / Sorry! |
| Es tut mir leid. | I'm sorry. |
| Kein Problem! | No problem! |

## Bitte — one word, three jobs

1. Asking: Ein Wasser, bitte. — A water, please.
2. Answering "danke": Danke! – Bitte! — Thanks! – You're welcome!
3. Offering: Bitte schön, Ihr Kaffee. — Here you are, your coffee.

## A short dialogue at the bakery

**Verkäuferin:** So, Ihre Brötchen. Bitte schön!
**Kunde:** Danke schön! Auf Wiedersehen!
**Verkäuferin:** Auf Wiedersehen! Schönen Tag noch!

> **Tip:** When someone wishes you "Schönen Tag noch!", answer "Danke, gleichfalls!" (Thanks, you too!).
