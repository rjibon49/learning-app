In Part 3 each person gets a **card with a picture** (or a word): a pen, a window, a glass of water, a phone … You make a **request** to another person. They react.

## Example

Card: 🪟 (window)
**Ali:** Kannst du bitte das Fenster öffnen?
**Mia:** Ja, gern. / Ja, natürlich.

Card: ✏️ (pen)
**Mia:** Kannst du mir bitte einen Kuli geben?
**Ali:** Hier, bitte. / Tut mir leid, ich habe keinen Kuli.

## Three ways to ask

| Deutsch | Use |
|---|---|
| Kannst du bitte …? | most common, friendly |
| Können Sie bitte …? | formal |
| Gib mir bitte … / Mach bitte … | imperative + bitte |
| Ich möchte bitte … | I'd like … |

## Picture → request

| Picture | Request |
|---|---|
| Fenster | Kannst du bitte das Fenster zumachen? |
| Wasser | Kannst du mir bitte ein Glas Wasser geben? |
| Handy | Kann ich bitte kurz dein Handy benutzen? |
| Licht | Mach bitte das Licht an. |
| Tür | Kannst du bitte die Tür aufmachen? |
| Buch | Kannst du mir bitte das Buch geben? |
| Uhr | Wie spät ist es, bitte? |
| Stuhl | Ist der Stuhl frei? Kann ich mich setzen? |

## Reacting

| Deutsch | English |
|---|---|
| Ja, gern. / Natürlich. | Yes, of course. |
| Hier, bitte. | Here you are. |
| Kein Problem. | No problem. |
| Tut mir leid, das geht nicht. | Sorry, that's not possible. |
| Tut mir leid, ich habe keinen/keine/kein … | Sorry, I don't have a … |

> **Tip:** Always say **bitte** — it is part of a correct request in German and the examiners listen for it.
