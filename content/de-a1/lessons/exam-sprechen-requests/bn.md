অংশ ৩-এ প্রত্যেকে একটা **ছবিওয়ালা কার্ড** (বা শব্দ) পায়: কলম, জানালা, এক গ্লাস পানি, ফোন … আপনি আরেকজনকে একটা **অনুরোধ** করবেন। সে সাড়া দেবে।

## উদাহরণ

কার্ড: 🪟 (জানালা)
**Ali:** Kannst du bitte das Fenster öffnen?
**Mia:** Ja, gern. / Ja, natürlich.

কার্ড: ✏️ (কলম)
**Mia:** Kannst du mir bitte einen Kuli geben?
**Ali:** Hier, bitte. / Tut mir leid, ich habe keinen Kuli.

## জিজ্ঞেস করার তিন উপায়

| Deutsch | ব্যবহার |
|---|---|
| Kannst du bitte …? | সবচেয়ে প্রচলিত, বন্ধুসুলভ |
| Können Sie bitte …? | আনুষ্ঠানিক |
| Gib mir bitte … / Mach bitte … | আদেশসূচক + bitte |
| Ich möchte bitte … | আমি … চাই |

## ছবি → অনুরোধ

| ছবি | অনুরোধ |
|---|---|
| Fenster | Kannst du bitte das Fenster zumachen? |
| Wasser | Kannst du mir bitte ein Glas Wasser geben? |
| Handy | Kann ich bitte kurz dein Handy benutzen? |
| Licht | Mach bitte das Licht an. |
| Tür | Kannst du bitte die Tür aufmachen? |
| Buch | Kannst du mir bitte das Buch geben? |
| Uhr | Wie spät ist es, bitte? |
| Stuhl | Ist der Stuhl frei? Kann ich mich setzen? |

## সাড়া দেওয়া

| Deutsch | অর্থ |
|---|---|
| Ja, gern. / Natürlich. | হ্যাঁ, অবশ্যই। |
| Hier, bitte. | এই নাও। |
| Kein Problem. | কোনো সমস্যা নেই। |
| Tut mir leid, das geht nicht. | দুঃখিত, সম্ভব না। |
| Tut mir leid, ich habe keinen/keine/kein … | দুঃখিত, আমার কাছে … নেই। |

> **টিপ:** সবসময় **bitte** বলুন — জার্মানে সঠিক অনুরোধের এটা অংশ, আর পরীক্ষকরা এটা খেয়াল করেন।
