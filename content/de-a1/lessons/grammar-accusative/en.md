The **Akkusativ** shows the **direct object** — the thing or person the action goes to. Question: **Wen? / Was?**

## Only masculine changes!

| | Nominativ | Akkusativ |
|---|---|---|
| masculine | der / ein / kein | **den / einen / keinen** |
| feminine | die / eine / keine | die / eine / keine |
| neuter | das / ein / kein | das / ein / kein |
| plural | die / – / keine | die / – / keine |

## Examples

| Deutsch | English |
|---|---|
| Ich kaufe einen Kaffee. | I'm buying a coffee. |
| Ich habe keinen Hunger. | I'm not hungry. |
| Sie sucht den Bahnhof. | She is looking for the station. |
| Wir brauchen eine Wohnung. | We need a flat. |
| Er liest das Buch. | He reads the book. |

## Verbs that take Akkusativ

haben, brauchen, kaufen, suchen, sehen, essen, trinken, lesen, nehmen, besuchen, kennen, möchten, finden, bestellen, es gibt.

- "Es gibt einen Park hier." — There is a park here.
- "Ich nehme den Fisch." — I'll have the fish.

## Pronouns in the Akkusativ

| Nominativ | Deutsch (Akkusativ) |
|---|---|
| ich | mich |
| du | dich |
| er | ihn |
| sie | sie |
| es | es |
| wir | uns |
| ihr | euch |
| sie/Sie | sie/Sie |

- "Ich liebe dich." — I love you.
- "Der Film? Ich finde ihn gut." — The film? I think it's good.

> **Tip:** "Ich habe einen …" is the sentence you will say most: einen Bruder, einen Termin, einen Hund.
