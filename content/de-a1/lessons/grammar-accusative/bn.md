**Akkusativ** দেখায় **কর্ম** — যে জিনিস বা ব্যক্তির উপর কাজটি যায়। প্রশ্ন: **Wen? / Was?**

## শুধু পুংলিঙ্গ বদলায়!

| | Nominativ | Akkusativ |
|---|---|---|
| পুংলিঙ্গ | der / ein / kein | **den / einen / keinen** |
| স্ত্রীলিঙ্গ | die / eine / keine | die / eine / keine |
| ক্লীবলিঙ্গ | das / ein / kein | das / ein / kein |
| বহুবচন | die / – / keine | die / – / keine |

## উদাহরণ

| Deutsch | অর্থ |
|---|---|
| Ich kaufe einen Kaffee. | আমি একটা কফি কিনছি। |
| Ich habe keinen Hunger. | আমার ক্ষুধা নেই। |
| Sie sucht den Bahnhof. | সে স্টেশন খুঁজছে। |
| Wir brauchen eine Wohnung. | আমাদের একটা ফ্ল্যাট দরকার। |
| Er liest das Buch. | সে বইটা পড়ছে। |

## যে ক্রিয়াগুলো Akkusativ নেয়

haben, brauchen, kaufen, suchen, sehen, essen, trinken, lesen, nehmen, besuchen, kennen, möchten, finden, bestellen, es gibt।

- "Es gibt einen Park hier." — এখানে একটা পার্ক আছে।
- "Ich nehme den Fisch." — আমি মাছটা নেব।

## Akkusativ-এ সর্বনাম

| Nominativ | Deutsch (Akkusativ) |
|---|---|
| ich | mich |
| du | dich |
| er | ihn |
| sie | sie |
| es | es |
| wir | uns |
| ihr | euch |
| sie/Sie | sie/Sie |

- "Ich liebe dich." — আমি তোমাকে ভালোবাসি।
- "Der Film? Ich finde ihn gut." — ছবিটা? আমার ভালো লাগে।

> **টিপ:** "Ich habe einen …" — এই বাক্যটাই সবচেয়ে বেশি বলবেন: einen Bruder, einen Termin, einen Hund।
