আপনি কী করেন, কোথায় কাজ করেন আর কেমন লাগে — বলুন।

## পেশা: পুরুষ আর মহিলা রূপ

বেশিরভাগ পেশায় মহিলাদের জন্য **-in** যোগ হয়:

| Deutsch | অর্থ |
|---|---|
| der Lehrer / die Lehrerin | শিক্ষক / শিক্ষিকা |
| der Arzt / die Ärztin | ডাক্তার |
| der Krankenpfleger / die Krankenpflegerin | নার্স |
| der Ingenieur / die Ingenieurin | প্রকৌশলী |
| der Verkäufer / die Verkäuferin | বিক্রেতা |
| der Koch / die Köchin | রাঁধুনি / শেফ |
| der Fahrer / die Fahrerin | চালক |
| der Student / die Studentin | ছাত্র / ছাত্রী |
| der Programmierer / die Programmiererin | প্রোগ্রামার |
| der Kellner / die Kellnerin | ওয়েটার |

নিজের পেশা বলার সময় **আর্টিকেল নেই**: "Ich bin Ingenieur." ("ein Ingenieur" নয়)।

## কাজ নিয়ে কথা

| Deutsch | অর্থ |
|---|---|
| Was sind Sie von Beruf? | আপনার পেশা কী? |
| Ich bin Krankenpflegerin von Beruf. | আমি পেশায় নার্স। |
| Wo arbeiten Sie? | আপনি কোথায় কাজ করেন? |
| Ich arbeite bei Siemens. | আমি সিমেন্সে কাজ করি। |
| Ich arbeite in einem Restaurant. | আমি একটা রেস্টুরেন্টে কাজ করি। |
| Ich arbeite Vollzeit / Teilzeit. | আমি পূর্ণকালীন / খণ্ডকালীন কাজ করি। |
| Ich bin arbeitslos. | আমি বেকার। |
| Ich suche Arbeit. | আমি কাজ খুঁজছি। |
| Ich mache eine Ausbildung. | আমি কারিগরি প্রশিক্ষণ নিচ্ছি। |

## কাজ কেমন?

- "Die Arbeit macht Spaß." — কাজটা মজার।
- "Meine Kollegen sind nett." — আমার সহকর্মীরা ভালো।
- "Die Arbeit ist anstrengend." — কাজটা ক্লান্তিকর।
- "Ich verdiene nicht so viel." — আমি অত বেশি আয় করি না।

> **টিপ:** কোম্পানির সাথে **bei** ("bei Siemens", "bei der Post"), জায়গার ধরনের সাথে **in** ("in einem Krankenhaus")।
