Say what you do, where you work and how you like it.

## Jobs: male and female forms

Most jobs add **-in** for women:

| Deutsch | English |
|---|---|
| der Lehrer / die Lehrerin | teacher |
| der Arzt / die Ärztin | doctor |
| der Krankenpfleger / die Krankenpflegerin | nurse |
| der Ingenieur / die Ingenieurin | engineer |
| der Verkäufer / die Verkäuferin | shop assistant |
| der Koch / die Köchin | cook, chef |
| der Fahrer / die Fahrerin | driver |
| der Student / die Studentin | student |
| der Programmierer / die Programmiererin | programmer |
| der Kellner / die Kellnerin | waiter / waitress |

**No article** when you say your job: "Ich bin Ingenieur." (not "ein Ingenieur").

## Talking about work

| Deutsch | English |
|---|---|
| Was sind Sie von Beruf? | What do you do (for a living)? |
| Ich bin Krankenpflegerin von Beruf. | I'm a nurse. |
| Wo arbeiten Sie? | Where do you work? |
| Ich arbeite bei Siemens. | I work at Siemens. |
| Ich arbeite in einem Restaurant. | I work in a restaurant. |
| Ich arbeite Vollzeit / Teilzeit. | I work full-time / part-time. |
| Ich bin arbeitslos. | I'm unemployed. |
| Ich suche Arbeit. | I'm looking for work. |
| Ich mache eine Ausbildung. | I'm doing vocational training. |

## How is your job?

- "Die Arbeit macht Spaß." — The work is fun.
- "Meine Kollegen sind nett." — My colleagues are nice.
- "Die Arbeit ist anstrengend." — The work is tiring.
- "Ich verdiene nicht so viel." — I don't earn much.

> **Tip:** **bei** + company ("bei Siemens", "bei der Post"), **in** + type of place ("in einem Krankenhaus").
