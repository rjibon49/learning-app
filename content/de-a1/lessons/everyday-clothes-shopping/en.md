## In the shop

| Deutsch | English |
|---|---|
| Kann ich Ihnen helfen? | Can I help you? |
| Ich suche eine Jacke. | I'm looking for a jacket. |
| Welche Größe haben Sie? | What size are you? |
| Größe M / 40. | Size M / 40. |
| Kann ich das anprobieren? | Can I try this on? |
| Wo sind die Umkleidekabinen? | Where are the changing rooms? |
| Die Hose ist zu groß / zu klein. | The trousers are too big / too small. |
| Haben Sie das eine Nummer kleiner? | Do you have it one size smaller? |
| Haben Sie das auch in Blau? | Do you also have it in blue? |
| Die Jacke steht Ihnen gut. | The jacket suits you. |
| Ich nehme sie. | I'll take it. |

## Talking about clothes (Akkusativ + pronouns)

- "Wie findest du den Pullover?" — "Ich finde **ihn** schön."
- "Wie findest du die Jacke?" — "Ich finde **sie** zu teuer."
- "Wie findest du das Kleid?" — "Ich finde **es** toll."

## Returning something

- "Ich möchte die Hose umtauschen." — I'd like to exchange the trousers.
- "Hier ist der Kassenbon." — Here's the receipt.

> **Tip:** German sizes: women's clothes often use 36, 38, 40 …; shoes use European sizes (38, 42 …).
