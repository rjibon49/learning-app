নয়টি অব্যয় **Dativ অথবা Akkusativ** দুটোই নিতে পারে। প্রশ্নই ঠিক করে:

- **Wo?** (কোথায় — অবস্থান, নড়াচড়া নেই) → **Dativ**
- **Wohin?** (কোথায় যাচ্ছে — কোনো জায়গার দিকে গতি) → **Akkusativ**

## নয়টি

| Deutsch | অর্থ |
|---|---|
| in | ভেতরে |
| an | গায়ে, পাশে (খাড়া জিনিসে) |
| auf | উপরে (ছুঁয়ে) |
| über | উপরে (না ছুঁয়ে) |
| unter | নিচে |
| vor | সামনে |
| hinter | পেছনে |
| neben | পাশে |
| zwischen | মাঝখানে |

## Wo? = Dativ / Wohin? = Akkusativ

| Wo? (Dativ) | Wohin? (Akkusativ) |
|---|---|
| Das Buch liegt auf dem Tisch. | Ich lege das Buch auf den Tisch. |
| Ich bin in der Küche. | Ich gehe in die Küche. |
| Das Bild hängt an der Wand. | Ich hänge das Bild an die Wand. |
| Die Katze sitzt unter dem Stuhl. | Die Katze läuft unter den Stuhl. |

## সংক্ষিপ্ত রূপ

in dem → **im**, in das → **ins**, an dem → **am**, an das → **ans**

- "Ich bin im Kino." — আমি সিনেমা হলে আছি।
- "Ich gehe ins Kino." — আমি সিনেমা দেখতে যাচ্ছি।

## ক্রিয়ার জোড়া

| Deutsch | অর্থ | প্রশ্ন |
|---|---|---|
| liegen | শুয়ে/পড়ে থাকা | Wo? |
| legen | শুইয়ে রাখা | Wohin? |
| stehen | দাঁড়িয়ে থাকা | Wo? |
| stellen | দাঁড় করিয়ে রাখা | Wohin? |
| hängen | ঝুলে থাকা / ঝোলানো | Wo? / Wohin? |
| sitzen | বসে থাকা | Wo? |
| setzen | বসানো | Wohin? |

> **টিপ:** নিজেকে জিজ্ঞেস করুন: কিছু কি নতুন জায়গায় যাচ্ছে? হ্যাঁ → Akkusativ। না → Dativ।
